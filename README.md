## Rasterization
A raster is a digital image made up of a rectangular grid of pixels. We can say that an occupancy grid is essentially a raster, where obstacles will be represented as filled in pixels.

Given a 3D point cloud, we will its 2D counterpart by projection to birds-eye view (BEV), and then rasterize this 2D point cloud to get its representation on an occupancy grid.
